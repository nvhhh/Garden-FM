Felucca flasher for FM-1

Installs the Felucca firmware on an M-VAVE FM-1 from this browser, over its USB-MIDI port. Build: main 5e185e6.

Before you start

  1. Connect the FM-1 to this computer with a USB cable that carries data (not a charge-only cable).
  2. Close any other app that uses the FM-1's MIDI port (its own editor, a DAW, MIDI-OX).
  3. Use Chrome, Edge or Opera on a desktop computer. Safari and Firefox do not offer Web MIDI.
  4. If the browser asks for MIDI access, allow it.
